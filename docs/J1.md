# Qestions à répondre

## Qui produit la mesure, qui la transporte, qui la conserve et qui l’affiche ?
Les capteurs produisent la mesure qui est transporté par mosquito via protocole. Celle ci est conservé par une base de donnée Postrgres avec l'extention TimescaleDB. Les données seront affiché par l'application mobile react native.

## Pourquoi une API et un broker ont-ils des rôles différents ?
Le broker fonctionne avec un système de publication/abonnement, il récupère les données, les filtres et les envoie à l'api.
L'api elle va stocker les données et permettre de faire des actions précise en se basant sur celle-ci.

## Qu’affiche le téléphone pendant le chargement ou si aucune mesure n’existe ?
Pendant le chargement des données un loader est affiché pour montrer à l'utilisateur que l'application charge. Et quand aucune data n'est trouvé, on le signale simplement à l'utilisateur.
